# Layout 의 이해

-`_app.tsx` 와 `_document.tsx` 의 역할을 한다.

1. \_app.tsx

- 공통적인 레이아웃을 가진 모든 페이지에서 사용될 템플릿
- 서버로 요청이 들어왔을 때 가장 먼저 실행되는 컴포넌트이다

2. \_document.tsx

- HTML 문서 전체에 적용될 공통적인 스타일, 스크립트, 메타 데이터 등을 정의하는 곳
- \_app.tsx 다음으로 실행되는 파일이다.
- 공통적으로 사용할 head, meta(뷰포트) 정보, body 등을 커스터마이징 할 수 있다.

3. layout.tsx

- 공통적으로 사용되는 UI 요소를 감싸는 컴포넌트이다.
- html 의 기본 구조 (<html>, <head>,<body>,<footer> )

```tsx
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import "./globals.css";

const geistSans = Geist({
  variable: "--font-geist-sans",

        <div style={{ border: "5px solid #ddd" }}>
          여기는 공통 레이아웃입니다
        </div>
        {children}
      </body>
    </html>
  );
```

# React 19 Server Component 의 이해

- React 18 버전에서 추가된 기능

## React Server Component (통칭 `rsc`)

- rsc 의 사전렌더링 자료는 `rscpayload` 라고 한다.

1. 서버 컴포넌트 (Server Component)

- 서버 부분에서 렌더링 되는 컴포넌트이다. 보통 최초 한번 실행된다.
- 번들링 전에 클라이언트 앱이나 SSR 서버와는 분리된 환경에서 미리 렌더링된다.
- 기본적으로 서버 컴포넌트를 사용하며, `use client` 라고 명시한다.

> 모든 컴포넌트는 **서버 컴포넌트가 기본이다**

2. 클라이언트 컴포넌트 (Client Component)

- 버튼 또는 검색창과 같이 사용자와 상호작용하는 작은 UI 들을 클라이언트 단에서 렌더링되는 컴포넌트 이다.
- 클라이언트 컴포넌트에서 서버 컴포넌트를 import 하지 않는다.
  : 써야 할 경우 `children` 으로 넘겨주자
-

|                             사용 이유                             | 서버 컴포넌트 | 클라이언트 컴포넌트 |
| :---------------------------------------------------------------: | :-----------: | :-----------------: |
|                          데이터 가져오기                          |      ✅       |         ❌          |
|                    백엔드 리소스에 직업 액세스                    |      ✅       |         ❌          |
|            민감한 정보 서버에 보관(액세스 토큰, API 키            |      ✅       |         ❌          |
|                서버에 대한 의존 클라이언트 js 감소                |      ✅       |         ❌          |
|                    상호작용 이벤트 리스너 추가                    |      ❌       |         ✅          |
| 상태 및 수명, 효과주기 (useState(), useReducer(), useEffect() 등) |      ❌       |         ✅          |
|                      브라우저 전용 API 사용                       |      ❌       |         ✅          |
|               상태, 효과 또는 사용자 정의 후크 사용               |      ❌       |         ✅          |
|                    React 클래스 구성요소 사용                     |      ❌       |         ✅          |

6. 검색창 기능 정리

- src\components\searchbar.tsx

```tsx
"use client";

import { useRouter } from "next/navigation";
import { useState } from "react";
import style from "@/components/searchbox.module.css";

const SearchBar = () => {
  const [search, setSearch] = useState<string>("");
  const onChangeSearch = (e: React.ChangeEvent<HTMLInputElement>) => {
    setSearch(e.target.value);
  };

  // 동적 라우팅
  const router = useRouter();
  const handleSearch = () => {
    if (!search) {
      return;
    }
    router.push(`/search?keyword=${search}`);
  };

  const onKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if ((e.key = "Enter")) {
      handleSearch();
    }
  };
  return (
    <div className={style.conteiner}>
      <input
        type="text"
        value={search}
        onChange={onChangeSearch}
        onKeyDown={onKeyDown}
        style={{ padding: "3px 10px" }}
      />
      <button
        onClick={handleSearch}
        style={{
          backgroundColor: "#000",
          color: "#fff",
          border: "none",
          padding: "5px 10px",
        }}
      >
        검색
      </button>
    </div>
  );
};

export default SearchBar;
```
